# Lupper

Jogo de terror em primeira pessoa. Uma noite numa casa no interior de São Paulo, em 2003.

## Download

**[Baixar para Windows (v1.0)](https://github.com/FSantos15/Lupper/releases/latest/download/Lupper-Windows-v1.0.zip)** — 214 MB

1. Extraia o `.zip` (o `Lupper.exe` e o `Lupper.pck` precisam ficar na mesma pasta).
2. Abra o `Lupper.exe`. Se o Windows avisar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o jogo não tem assinatura digital).

Requisitos: Windows 10/11 64 bits, placa de vídeo com DirectX 12 ou Vulkan.

## Controles

W A S D andar · Shift correr · Ctrl/C agachar · E interagir · F isqueiro · Clique golpear · Esc pausa (também funciona com controle)

Feito com Godot 4.7.
